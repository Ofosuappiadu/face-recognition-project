# Face Recognition Project

## Project Overview
This project aims to develop a face recognition system that identifies a specific individual and classifies other faces as unknown.

## Objectives
- Collect and organize images of the target individual.
- Prepare and annotate the dataset.
- Explore suitable computer vision and machine learning techniques.
- Evaluate the model's recognition performance.

## Tools and Technologies
- Python
- Ultralytics
- Google Drive
- Git and GitHub
- Ollama with Llama 3.2 1B

## Dataset
The initial dataset contains images of the target individual captured under different lighting conditions, angles, and backgrounds.

## Expected Outcome
A prototype that recognizes the target individual and labels unrecognized faces as unknown.

## Project Status
Initial dataset collection and preparation.
